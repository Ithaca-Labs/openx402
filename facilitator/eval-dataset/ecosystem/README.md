# Live evaluation cohort workspace

This directory is the local workspace for the unified evaluation program's
live x402 cohort. Run `npm run benchmark:run` from `facilitator/` to refresh,
probe, validate, and report both controlled and live evidence. Raw third-party
responses and the normalized catalog are ignored until redistribution terms
are confirmed.

The checked-in query seed is adapted from the frozen release query set so the
live cohort starts with the same information needs. Replace or extend
it with curated ecosystem queries, then import pooled judgments and observed
outcomes using the commands in `docs/ECOSYSTEM-BENCHMARK.md`.
