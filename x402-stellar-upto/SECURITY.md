# Security policy

This repository is a pre-audit protocol and contract proposal. Do not use the
testnet deployment or optional reference policy to protect production funds.

Report suspected vulnerabilities privately to the repository maintainers. Do
not include private keys, signed production authorizations, or exploitable
public transaction instructions in a public issue before coordination.

The intended audit scope is documented in [the threat model](docs/THREAT_MODEL.md).
Production support begins only after ABI freeze, external audit, remediation,
and publication of audited artifact hashes.
