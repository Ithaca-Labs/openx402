# openx402 1024×1024 social colorways

Each colorway is a separate native 1024×1024 SVG and PNG. Every file uses the approved canonical mark paths at the same centered scale. No previous raster was resized or reused.

## Preferred

- `openx402-yellow-on-ink-1024` — primary social avatar
- `openx402-ink-on-yellow-1024` — primary inverse
- `openx402-ink-on-paper-1024` — warm neutral

## Monochrome

- `openx402-white-on-ink-1024`
- `openx402-ink-on-white-1024`

## Alternate

- `openx402-white-on-yellow-1024` — low contrast; avoid at small sizes
- `openx402-yellow-on-white-1024` — low contrast; avoid at small sizes

## Transparent

- `openx402-black-transparent-1024`
- `openx402-white-transparent-1024`
- `openx402-yellow-transparent-1024`

Opaque variants use a full square background. No file contains a circle. Platforms may apply their own display crop.
