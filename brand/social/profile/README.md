# Native social profile logo set

Use `x-avatar-primary-400.png` for X. Every platform file is authored at its native target dimensions directly from the canonical mark paths. No previous raster or resized export is used.

All opaque assets keep the full square background. Platforms may apply their own display crop.

## Platform exports

- `x-avatar-primary-400.{svg,png}` — X, 400×400
- `linkedin-avatar-primary-400.{svg,png}` — LinkedIn Page, 400×400
- `github-avatar-primary-500.{svg,png}` — GitHub, 500×500
- `discord-avatar-primary-512.{svg,png}` — Discord, 512×512
- `social-avatar-primary-master-1024.{svg,png}` — high-resolution master

## Colorways

- `avatar-primary-dark-400` — Signal Yellow mark on full Ink background; preferred
- `avatar-primary-light-400` / `avatar-primary-light-1024` — Ink mark on full Signal Yellow background
- `avatar-paper-400` — Ink mark on full Paper background
- `avatar-mono-white-400` — white mark on full Ink background
- `mark-safe-{black|white|yellow}-transparent-1024` — transparent mark versions
- [`1024-colorways/`](./1024-colorways/) — complete set of 10 separate native 1024×1024 SVG and PNG colorways
- [`openx402-social-avatar-colorways-1024.zip`](./openx402-social-avatar-colorways-1024.zip) — downloadable 1024 colorway pack

## Geometry

The mark is copied exactly from the approved canonical design and scaled uniformly. At 400×400 it uses `translate(70 70) scale(2.6)`, giving approximately 22% visible padding on each side. Do not enlarge the mark inside these social artboards.
